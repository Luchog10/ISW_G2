## Convención de nombres

Los archivos deberán respetar las reglas de nombrado establecidas por la cátedra.

### Ejemplos

```text
ISW_G2_TPEval.pdf
ISW_G2_CG_<Año>.mp4
```

Donde:

* `<Año>`: año académico correspondiente.
* `G2`: identificación del grupo.
* `TPEval`: Trabajo Práctico evaluable.
* `CG`: clase grabada.
* `.pdf`, `.mp4`, etc.: extensión correspondiente al tipo de archivo.

Por ejemplo:

```text
ISW_G2_TPEval1.pdf
```
